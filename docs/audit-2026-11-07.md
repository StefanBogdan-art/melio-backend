# Melio audit (7 Nov 2026): backend, frontend and iOS

Method: three read-only agents. Backend tested locally against mocks (only 5 harmless requests to prod). Frontend tested headless in Chromium with mocks. iOS checked through config files plus `cap sync` in a scratch copy; the Xcode build is blocked until the Xcode license is accepted.
Nothing has been fixed yet. Line numbers refer to the files as of 18 Oct.

## Refactor before iOS? No.
- The iOS changes are local: the AdMob block, the notifications, AbortSignal, the share link, plus plist and assets.
- The JS has no Android-only branches, only `isNativePlatform()`.
- Risk to watch: functions defined twice. `runAI`, `handleBonPhoto`, `showUrgentRecipes`, `saveFridge` and `translateApp` each have two definitions, and `fetch` is wrapped twice.
- Before editing a function, grep for its name and change the last (active) definition.

## Batch 2: Family Fridge security
- **B1 (critical):** RLS is off and the anon key is in the APK, so anyone can read or delete every household and chat directly in Supabase. Fix: enable RLS (backend uses the service key) and keep the existing polling.
- **B3/B4/B5:** no per-member auth; the 6-digit code can be brute-forced; joining with an existing name hijacks that member. Fix: a member token plus a rate limit on `/join`.
- **B2:** `X-Melio-App` is not checked on the server, and the secret is a placeholder.

## Batch 3: iOS
- **Bogdan (sudo/accounts):**
  - `sudo xcodebuild -license accept`
  - Apple Developer account and an App Store Connect record for `ro.melio.app`
  - an iOS app in AdMob, giving an iOS app id and an iOS banner id
  - a 1024×1024 icon with no transparency
- **Code and config:**
  - Run `npx cap sync ios`; the iOS copy is from August and only AdMob is registered.
  - Info.plist and project:
    - display name `Melio` (currently "npx cap init")
    - `arm64`
    - `ITSAppUsesNonExemptEncryption=false`
    - `SKAdNetworkItems`
    - `UIUserInterfaceStyle=Light`
    - portrait only
    - iPhone only
    - version 1.25 (25)
    - `PrivacyInfo.xcprivacy`
  - AdMob: platform switch for the ids, plus UMP/GDPR consent (Android needs it too).
  - Notifications: cap at 60 on iOS (iOS keeps only 64); `melio_chime.wav` in the bundle plus a `sound` field.
  - Add an `AbortSignal.timeout` polyfill, or set the iOS 16 minimum.
  - F10: Edit profile is a dead end on iOS (no back button, name gets overwritten).
  - Safe area on modals and footers; keyboard over the chat (test on device).
  - The fake AD placeholders with real brand names (App Review risk).
  - App Store share link; disable the IP prompt (5 taps).
